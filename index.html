Desenvolvimento Web com foco em experiência

Projeto acadêmico de portfólio profissional focado em design de interfaces modernas, responsividade e boas práticas de UI.

Sobre o Projeto

Este projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas da UNIP. O objetivo é apresentar um portfólio profissional simulando uma equipe de desenvolvimento web, com foco em design de interface, organização visual e responsividade.

Utilizamos tecnologias modernas de desenvolvimento front-end como HTML, CSS e o framework Tailwind CSS para criar uma interface limpa, responsiva e com boa experiência de usuário.

Tecnologias Utilizadas

  • HTML5
  • CSS3
  • Tailwind CSS
  • Design Responsivo
  • UI / UX
